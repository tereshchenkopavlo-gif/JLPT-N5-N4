**Початкова версія v1. Це ще не повний курс N5/N4.** Один автономний HTML, два рівні, українські пояснення. Кана вже відома; окремого курсу абетки немає.

80 слів, 24 граматичні теми, 12 зв’язних текстів, 64 питання. По 40 слів, 12 тем та 6 текстів на рівень. N4 може включати повторення N5 без дублювання прогресу. Для 64 із 80 слів окремі вправи ще не створені; вони доступні як картки.

Картки, пошук, фуріґана, вправи з поясненнями, читання з перекладом, 13 порівнюваних пар і 4 антонімічні пари, самооцінка S/G/X, просте повторення, JSON-резервна копія. Незавершена сесія зберігається після перезавантаження. Прогрес N1 незалежний і не імпортується сюди.

Сучасного офіційного вичерпного списку JLPT немає. Позначки N5/N4 — редакторський навчальний орієнтир. Не є офіційним продуктом JLPT чи пробним іспитом. Аудіювання поки відсутнє.

## Прогрес

Зберігається в локальному сховищі браузера. Інший пристрій, браузер або шлях HTML може мати інше сховище. Експортуйте JSON у 設定 перед переходом. Імпорт перевіряє формат та просить підтвердити заміну. Без доступу до сховища застосунок показує попередження; експортуйте прогрес до закриття вкладки.

## Збірка та перевірки

Збірка потребує Python 3, запуск готового HTML — лише браузера.

```sh
python3 build.py
python3 tests/content.py
```

Браузерні тести нижче призначені для Linux; бінарник Chromium і тестовий шрифт не входять до продукту. Каталог `../jlpt-n5-n4-test-runtime` є окремим тестовим середовищем.

```sh
npm install --prefix ../jlpt-n5-n4-test-runtime playwright@1.62.1 @sparticuz/chromium@143.0.4 @fontsource/noto-sans-jp@5.2.5
node tests/setup-browser.cjs
NODE_PATH="$(pwd)/../jlpt-n5-n4-test-runtime/node_modules" node tests/browser.cjs
```

Результати в `reports/`. Скриншоти та штучний тестовий прогрес — лише в тестовому середовищі; не комітити їх як дані користувача.

`write-report.py` формує звіт поточного v1 після успішних тестів. При наступних версіях оновити скрипт під фактичний обсяг, не перезаписувати історичні звіти новими результатами.
